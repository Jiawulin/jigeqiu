# 记个球 JIGEQIU

**把收藏整理成你的个人工作台。**

记个球是一款可本机部署、一条命令即可启动的网址收藏管理工具。以桌面快捷方式、
启动台和全局搜索连接日常浏览，用多层目录整理收藏，让常用网站随手可达。
无需注册账号，无需业务后端、数据库或 API Key。可作为 Chrome / Edge
新标签页扩展使用，也可自行部署 Web 网页版。

## 快速开始

### 先选使用方式

从 [Releases](https://github.com/jiawulin/jigeqiu/releases) 的 **Assets** 下载，
下面的 `X.Y.Z` 替换为所选版本号；通常只需选择一个 ZIP。

| 你的需求 | 下载文件 | 下一步 |
| --- | --- | --- |
| 将 Chrome / Edge 新标签页变成工作台 | `jigeqiu-extension-X.Y.Z.zip` | [安装浏览器扩展](#安装浏览器扩展免编译) |
| 部署到自己的域名、服务器或静态托管平台 | `jigeqiu-vX.Y.Z-web.zip` | [部署 Web 网页版](#部署-web-网页版免编译) |
| 开发、修改代码或自行构建 | 克隆仓库或下载 Source code | [源码运行](#源码运行开发使用) |
| 校验下载文件是否完整 | `SHA256SUMS.txt` | [下载校验](#下载校验可选) |

**两个 ZIP 不能混用。** Web 包不是浏览器扩展；扩展包无需上传到网站。
GitHub 自动附带的 **Source code (zip / tar.gz)** 是源码，不是构建好的 Web 或扩展包。

### 安装浏览器扩展（免编译）

适合想直接使用新标签页工作台的 Chrome / Edge 用户，无需安装 Node.js、
运行命令或准备网站服务器。

1. 下载 `jigeqiu-extension-X.Y.Z.zip`，解压到一个准备长期保留的固定目录。
2. Chrome 在地址栏输入 `chrome://extensions`；Edge 输入 `edge://extensions`。
3. 开启“开发者模式”（Edge 为“开发人员模式”）。
4. 点击“加载已解压的扩展程序”（Edge 为“加载解压缩的扩展”），选择
   **直接包含 `manifest.json` 的目录**，不要选择 ZIP 或不含清单的外层目录。
5. 打开新标签页；如浏览器询问是否保留更改，请确认。首次进入时阅读隐私说明。

这不是 CRX 双击安装包，也不表示已通过扩展商店安装。不要删除或移动解压后的
目录，浏览器仍需从该目录读取文件。若另一个扩展接管新标签页，请先处理冲突。
“离线安装包”表示安装使用本地文件，不代表加载远程图标、搜索或打开网站无需网络。

#### 扩展更新与数据

1. 先在 **管理中心 → 导入与导出 → 资产备份恢复** 导出资产备份，保存到浏览器之外。
2. 关闭已打开的记个球扩展页面，用新版包的完整内容更新**原安装目录**，
   保持目录与扩展身份不变。
3. 在扩展管理页点击“重新加载”，再打开新标签页核对版本和收藏。

**不要先卸载旧扩展再安装新版**，卸载可能删除本地数据。资产备份包含收藏、搜索引擎、
桌面文件夹和任务栏固定项，但不包含壁纸、外观、历史、回收站或图标缓存。网页、Chrome 和 Edge 的数据不会自动同步；
跨版本或浏览器迁移前先备份，网页到扩展需手动导出／导入。
开发构建、存储和测试说明见[扩展文档](extension/README.md)。

### Web 部署的安全要求

> **公网或局域网部署必须使用 HTTPS，才能正常执行受保护的保存操作。**
> 添加／编辑收藏、管理中心删除、确认 HTML／JSON 导入等操作依赖 Web Locks，
> 用于协调多个标签页的写入，避免相互覆盖。普通 HTTP 域名或局域网 IP 下页面虽然能打开，
> 但缺少 Web Locks 时这些操作会被明确拒绝，并不是仅提示风险后继续保存。
> 本机通过 `http://localhost` 或 `http://127.0.0.1` 访问是例外，无需配置本机证书；
> 仍需浏览器支持 Web Locks 并允许站点存储。

### 源码运行（开发使用）

环境要求：Node.js 24.x、npm 10.8.2 或更高版本，以及支持 Web Locks 的现代浏览器。

克隆本仓库，或下载源码 ZIP 并解压：

```sh
git clone https://github.com/jiawulin/jigeqiu.git
```

进入项目目录，安装依赖并启动：

```sh
cd jigeqiu
npm install
npm run dev
```

下载 ZIP 时，将 `cd` 路径替换为解压后的源码目录。

浏览器打开 **[http://127.0.0.1:3000](http://127.0.0.1:3000)**。
无需业务后端或数据库，保持启动进程运行即可。

#### 可选配置

将 `.env.example` 复制为 `.env`，可通过 `HOST` 修改监听地址、`PORT` 修改端口，
或设置 `DISABLE_HMR=true` 关闭开发热更新与文件监听；系统环境变量优先。
默认配置无需创建 `.env`，修改端口后请访问对应地址。
默认仅监听本机地址 `127.0.0.1`；局域网访问可设置 `HOST=0.0.0.0`，
请仅在可信网络中使用，并通过 HTTPS 访问。

### 部署 Web 网页版（免编译）

无需安装 Node.js，也无需自行编译。

1. 从 Releases 下载所选版本的 `jigeqiu-vX.Y.Z-web.zip`，不要下载 extension 包或 Source code。
2. 将 ZIP 内的文件解压到 Nginx 站点根目录，确保根目录直接包含 `index.html`、`assets/` 和 `wallpapers/`。
3. 配置站点并重载 Nginx，在浏览器访问站点地址。

本机 Nginx 配置示例（按实际路径修改 `root`）：

```nginx
server {
    listen 127.0.0.1:8080;
    server_name localhost;
    root /var/www/jigeqiu;
    index index.html;

    location / {
        try_files $uri $uri/ =404;
    }
}
```

检查配置并重载后，打开 **[http://127.0.0.1:8080](http://127.0.0.1:8080)**：

```sh
nginx -t
nginx -s reload
```

以上 HTTP 配置仅用于本机回环地址；通过局域网 IP 或正式域名访问时，必须配置 HTTPS，
并将 HTTP 请求重定向到 HTTPS，否则依赖 Web Locks 的保存操作会被拒绝。
可用发布附件 `SHA256SUMS.txt` 校验下载包。项目使用 Hash 路由，无需额外的 SPA 路由重写。

升级时先导出资产备份，再更新完整站点文件并保留原域名、协议和端口。
站点地址改变不会自动带走原浏览器数据，需要导出后导入。
不要双击解压后的 `index.html`，请通过静态服务地址访问。

### 下载校验（可选）

将两个 ZIP 和同一版本的 `SHA256SUMS.txt` 放到同一目录，执行：

```sh
sha256sum --check SHA256SUMS.txt
# macOS
shasum -a 256 -c SHA256SUMS.txt
```

只下载一个 ZIP 时，该命令会提示另一个包缺失，并不表示已下载的包损坏。
也可单独计算文件的 SHA256，与校验文件中对应名称的行比较。

## 使用指南

### 导入已有书签

1. 在浏览器书签管理器中将书签导出为 HTML 文件。
2. 打开记个球，进入 **管理中心 → 导入与导出 → 收藏导入导出**，在上方“导入收藏”选择 **浏览器书签 · HTML**。
3. 选择文件，检查导入预览并确认。
4. 在 **全部收藏** 中查看目录与网址，按需整理。

导入入口以 Chrome 书签 HTML 格式为主；其他浏览器导出文件请先检查预览结果。
预览和取消操作不会写入收藏库，导入也不会自动铺满桌面。

### 构建个人桌面

- 在桌面添加收藏，或从收藏库、启动台将已有收藏固定到桌面。
- 用收藏库目录管理资产，用桌面文件夹组织快捷方式，两者互不影响。
- 将常用收藏固定到任务栏，或通过启动台访问全部收藏。
- 在 **管理中心 → 外观** 中切换主题、选择壁纸或上传本地背景图片。

从桌面移除快捷方式、取消任务栏固定不会删除原收藏。
删除收藏会进入回收站；恢复后可按需重新固定。

### 搜索与快捷指令

全局搜索支持标题、域名和关键词，也可将输入交给选定的搜索引擎。
启动台另提供拼音检索。搜索引擎可以从内置候选库添加，或配置自定义引擎。
在搜索框输入 `/` 即可查看可用指令列表。

| 指令 | 操作 |
| --- | --- |
| `/all` | 打开全部收藏 |
| `/start` | 打开启动台 |
| `/add` | 添加收藏 |
| `/search` | 管理搜索引擎 |
| `/theme` | 打开外观设置 |
| `/dark`、`/light` | 切换夜间、日间模式 |
| `/trash` | 打开回收站 |
| `/help` | 打开使用指南 |

桌面右下角的使用指南提供快捷键、搜索指令和操作说明。

### 备份与迁移

在 **管理中心 → 导入与导出** 中：

- **收藏导入导出**：浏览器 HTML 交换、收藏资产 JSON 导出与合并；不会改变搜索引擎、桌面或任务栏。
- **资产备份恢复**：导出收藏、目录、网址单兼容数据、搜索引擎及默认项、桌面文件夹与图标、任务栏固定项及顺序。

收藏页上方导入、下方导出，各自独立选择 HTML 或 JSON；两组格式均平铺显示为方框单选项。问号图标可悬停、键盘聚焦或点击查看格式区别：
HTML 用于浏览器书签交换，JSON 用于保留记个球专属收藏字段；连同工作台一起备份请使用资产标签。

恢复前显示“当前 → 恢复后”预览。收藏资产必须替换，搜索引擎、桌面、任务栏可分别选择；
未选择的布局保留有效入口，失效入口提前列出。现有回收站保留，身份冲突阻止恢复。
完整备份也能在收藏标签明确选择“仅合并其中的收藏资产”，不会隐式恢复工作台。
两类 JSON 按文件内容识别，改名不会改变类型：收藏 JSON 误选到资产恢复时会阻止恢复并提供切换入口；
完整备份误选到收藏导入时会提示前往资产恢复，或显式选择仅合并收藏。选择文件不会自动写入。
资产页区分“收藏文件夹”与“桌面文件夹”，不陈列尚未开放的历史网址单统计，旧兼容数据仍随备份保留。
两种 JSON 均不包含回收站、使用历史、语言、壁纸、外观、图标缓存或临时窗口。
保存图标配置但不下载远程图标，不保证离线图标可用。
请定期将备份保存在浏览器之外，尤其是在清除站点数据或更换部署地址之前。

## 自行部署

### 构建

```sh
npm ci
npm run build
```

### 发布静态文件

将 **完整 `dist/` 目录内的文件**上传到 HTTPS 站点根目录：

```text
站点根目录/
├── index.html
├── favicon.ico
├── assets/
└── wallpapers/
```

可使用 Nginx、Caddy 或支持 HTTPS 的静态托管平台。
生产环境只分发静态资源，不需要运行 Express、Node.js 或数据库服务。

本地预览构建产物：

```sh
npm run preview
```

部署要求：

- 正式域名及局域网 IP 使用 HTTPS；本机 `localhost`、`127.0.0.1` 可使用 HTTP。受保护写入需要安全上下文、Web Locks 和可用的浏览器存储。
- 默认构建部署到站点根路径，保留完整资源目录。直接打开 `file://` 文件不是运行方式。
- 页面使用 Hash 路由，例如 `/#/library`，无需应用层路由重写。
- 开发服务器用于本机开发，生产环境使用静态文件服务器。

HTTPS 是使用安全上下文 API 的必要条件之一，不保证所有浏览器都提供 Web Locks，
也不保证浏览器允许存储。不要通过移除写锁检查来解决部署问题。
新手引导的轻量 Cookie 回退仅用于记住欢迎引导已展示，不解除收藏保存或导入的限制。

## 数据与隐私

Web 版收藏与偏好存储在浏览器 LocalStorage 中；扩展版使用当前扩展的
`chrome.storage.local`，不提供账号同步。图标缓存及自定义壁纸存储在 IndexedDB 中。
网站服务器负责分发应用文件，不托管你的收藏库。Web 与扩展、不同浏览器配置之间
数据彼此独立，不会因安装扩展或升级网页而自动合并。

在非安全HTTP地址访问时，仅新手引导回退到最长400天的轻量Cookie，
记住欢迎引导已展示，不保存收藏内容或完整任务进度。该Cookie会随同主机请求发送；
浏览器清理或策略可能使其提前失效。相关通知约6秒自动关闭，悬停或焦点进入时暂停，
同类通知在当前页面会话内不重复。此回退不解除收藏、导入等受保护写入的HTTPS／Web Locks要求。

清除站点数据、删除浏览器配置或结束隐私会话可能导致本机数据丢失。
浏览器存储容量受浏览器和设备限制；回收站不能替代独立备份。

在线字体、网站图标及主动打开的外部网站会产生网络请求。
请使用可信构建和独立站点来源，不要在公开 issue 中附带私人网址、
真实书签备份、Cookie 或密钥。

例如版本已改为 `0.1.4` 时：

```sh
git tag v0.1.4
git push origin v0.1.4
```

**只推送 tag，不要提前在 Releases 页面公开空版本。** 发布工作流会执行完整检查，
构建两个 ZIP 与合并校验文件，创建草稿并上传，下载回验通过后自动公开。
新建 Release 会自动附带两个包各自的用途、安装和更新说明；无需手动点发布，
公开后可以补充本次变更说明。已有 Release 的描述不会被脚本覆盖。
普通 `master` 推送更新 Pages 演示站和扩展临时 Artifact，不创建正式 Release。
